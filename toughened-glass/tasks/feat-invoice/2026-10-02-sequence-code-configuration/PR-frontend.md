## Why

Users had no interface to view or customize the identifiers generated by the ERP. Each module either displayed internal IDs or unformatted running numbers. The Sequences page gives administrators full visibility and control over numbering formats, while ensuring the UI is completely consistent with other Master Data screens.

## How

**Sequences master page**: Created `/admin/sequences` following the exact design pattern of Work Centers and Charges. It includes KPI cards showing Configured Modules, Module Coverage percentage, and Format Structure.

**Interactive configuration modal**: Created SequenceDialog with react-hook-form and Zod validation. Selecting a module auto-suggests default prefixes, and editing any field updates a live preview box showing the exact formatted output.

**Table integration**: Replaced raw booking numbers in Order Booking table with human-readable sequence codes (`ORD-20261001-101`), and prioritized code columns across the PI Status table.

## Decisions made

**Used Module Coverage instead of static Date Pattern in KPI card.** The Date Pattern card previously displayed static text (YYYYMMDD) which was inaccurate because Company uses NONE and other modules can choose different patterns. Replacing it with dynamic Module Coverage (e.g. 100% when all 6 modules are configured) gives real operational value.

**Restored standard FilterTabs in toolbar.** FilterTabs was retained on the left side of FilterToolbar with an All pill matching the styling across other master data pages.

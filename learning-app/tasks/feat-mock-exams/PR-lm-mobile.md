The mobile app showed a "coming soon" card for mock exams and had no timer on practice. It needs the backend from `PR-learning-app-backend.md`. Checked with `npx tsc --noEmit` and `npx expo lint`; I did not run the app on a phone or emulator, and this project has no test runner, so there are no automated tests for the new code.

**The scaled score on the profile is not included on purpose** - see "Notes" below. This was a choice, not a miss.

## Why

Students take admin-built exams with a countdown, see their score on submit and review every answer, and can time their own practice.

## How

**The server owns the clock.** The app turns the server's seconds left into a clock time once (`deadlineAt`) and the timer counts to it. Each saved answer corrects it, and coming back to the app asks the server again. At zero the app asks the server to close the section or the exam; the server decides.

**No answers during an exam.** The exam screen never has the right answer; tapping a chosen answer again clears it. The review is requested only after the exam is finished.

**Section timers.** Only the open section's questions are shown. Finishing a section asks first and is final; the next section starts at question 1 with its own clock.

**Letters follow what is shown.** Options are lettered by position and never sorted on the phone.

## Decisions made

**Mock exams live under the Tests tab, not a new tab.** A card opens the list, so the tab bar stays as it is.

**The review star on the exam screen is a flag.** It marks a question for review inside the exam. It is not the practice bookmark.
